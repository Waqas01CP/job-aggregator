that every session reads at the start. `STATE.md` is 23,334 bytes after the
move. A DONE row is finished history, never
deleted, so the file grew monotonically with completed work while the rows a
session acts on stayed a small minority.

**How to read a row.** Exactly as in `STATE.md`. `[VERIFIED]` means exercised
and observed, `[BELIEVED]` means reasoned from the code but not run, and
unmarked means believed. `Proof` is a commit, a decision record or a log
filename, never a file path.

**How to maintain it.** When a row in `STATE.md` becomes DONE, move it here in
the same commit. Never delete a row from this file. If work is redone,
supersede the row with a new one rather than editing the old.
